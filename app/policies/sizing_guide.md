1. How to measure
Use a soft tape measure. Keep it snug but not tight. Measure chest at the fullest point, waist at the natural waistline, and length from the highest shoulder point to the hem.

2. Shirt size chart (measurements in cm)
Size S: chest 88 to 94, waist 74 to 80.
Size M: chest 96 to 102, waist 82 to 88.
Size L: chest 104 to 110, waist 90 to 96.
Size XL: chest 112 to 118, waist 98 to 104.

3. Fit notes
Classic Oxford Shirts (TS-204) run slightly slim. If you are between sizes, choose the larger one. Relaxed-fit tees run true to size.

4. Denim
Denim sizes use waist and inseam, for example 32 x 30. Raw denim can stretch up to 1 cm after the first few wears. Buy true to size, or go half a size down if you want a snugger fit.

5. Size exchanges
You can exchange for a different size within 30 days, provided the item is in stock. Size exchanges are free. See the Exchanges Policy for details.

6. Still unsure?
Contact support with your height, weight, and the item you want. A fit specialist will recommend a size. This service is free.
